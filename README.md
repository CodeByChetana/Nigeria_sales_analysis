# 🇳🇬 Nigeria Sales Data Analysis

📌 Project Overview  
This project focuses on cleaning, preprocessing, and analyzing a Nigeria sales dataset using Python and Pandas. The goal is to extract meaningful insights and understand sales patterns across different dimensions.

---

🎯 Objectives

- Understand the dataset structure  
- Handle missing and inconsistent data  
- Perform exploratory data analysis (EDA)  
- Identify sales trends and patterns  
- Generate business insights  

---

🛠️ Technologies Used

- Python  
- Pandas  
- Matplotlib  
- Google Colab  
- GitHub  

---

🧹 Data Cleaning

The following preprocessing steps were performed:

- Checked dataset shape and structure  
- Handled missing values  
- Converted date columns to proper format  
- Cleaned categorical columns  
- Removed inconsistencies  
- Dropped irrelevant or low-quality columns  

---

📊 Analysis Performed

- Sales distribution by channel  
- Average unit price by product  
- Sales analysis by state/region  
- Time-based analysis (year/month trends)  
- Channel vs pricing comparison  

---

📈 Key Insights

- Direct sales channel is the most frequently used channel.  
- Phones have the highest average unit price, indicating premium products.  
- Katsina state shows the highest pricing trends.  
- Wholesale channel has the highest average pricing.  
- Sales patterns show variation across different years and months.
